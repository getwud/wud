# Version 6.x

Release history and details for the **WUD 6.x** series.

---

## [6.6.1](https://github.com/getwud/wud/releases/tag/6.6.1) · <small>October 5, 2024</small>

:::warning[**Breaking changes!**]
**Home Assistant Update Sensors**: Home Assistant sensors are now created as `update` entities instead of `binary` sensors.
- Existing Home Assistant entities must be manually cleaned up.
- Remember to update your Home Assistant automations and dashboards accordingly.
:::

- 🚀 `API` / `UI` Add option to allow/disallow delete operations (`WUD_SERVER_FEATURE_DELETE`)
- 🚀 `APPRISE` Add support for [Apprise persistent YAML configuration](https://github.com/caronc/apprise/wiki/config_yaml)
- 🚀 `DISCORD` Add [Discord](../configuration/triggers/discord/README.md) trigger
- 🚀 `DOCKER` / `DOCKER-COMPOSE` Allow pruning old image versions (except current and candidate versions)
- 🚀 `FORGEJO` Add support for [Forgejo](../configuration/registries/forgejo/README.md) registries
- 🚀 `GCR` Allow anonymous access for public images
- 🚀 `GITEA` Add support for [Gitea](../configuration/registries/gitea/README.md) registries
- 🚀 `HTTP` Add support for Basic and Bearer authentication
- 🚀 `HTTP` Add HTTP proxy support
- 🚀 `MQTT` / `HOME ASSISTANT` Replace binary sensors with [update sensors](https://www.home-assistant.io/integrations/update/)
- 🚀 `MQTT` Add Home Assistant global sensors (total containers, pending updates, etc.)
- 🚀 `MQTT` Prefix client ID with `wud_` instead of generic `mqttjs_`
- 🚀 `TELEGRAM` Add [Telegram](../configuration/triggers/telegram/README.md) trigger
- 🚀 `UI` Add dark mode support and filter dropdown for update types
- 🚀 `UI` Auto-focus login input field and make filter values bookmarkable via URL
- 🚀 `UI` Make watcher and registry names visible when container cards are collapsed
- 🚀 Add `watcher` variable to trigger notification templates
- 🔧 Optimize Docker image footprint, update dependencies, and upgrade to Node.js 18
