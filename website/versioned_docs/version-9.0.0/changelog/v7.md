# Version 7.x

Release history and details for the **WUD 7.x** series.

---

## [7.2.0](https://github.com/getwud/wud/releases/tag/7.2.0) · <small>December 19, 2024</small>

- 🚀 `TRIGGER` Add support for associating specific triggers with specific containers
- 🚀 `UI` General UX improvements and styling polish
- 🚀 `UI` / `API` Add support for manually running triggers to assist with testing

---

## [7.1.1](https://github.com/getwud/wud/releases/tag/7.1.1) · <small>November 12, 2024</small>

- 🐛 `NTFY` Fix Basic and Bearer authentication headers

---

## [7.1.0](https://github.com/getwud/wud/releases/tag/7.1.0) · <small>November 11, 2024</small>

- 🚀 `GOTIFY` Add support for [Gotify](../configuration/triggers/gotify/README.md) trigger
- 🚀 `NTFY` Add support for [ntfy](../configuration/triggers/ntfy/README.md) trigger
- 🚀 `PUSHOVER` Add support for HTML templating
- 🐛 `UI` Fix container list sorting behavior

---

## [7.0.0](https://github.com/getwud/wud/releases/tag/7.0.0) · <small>October 21, 2024</small>

:::warning[**Breaking changes!**]
**WUD has moved to its own GitHub organization!**
- GitHub repository: [https://github.com/getwud/wud](https://github.com/getwud/wud)
- Docker image: [https://hub.docker.com/r/getwud/wud](https://hub.docker.com/r/getwud/wud)
:::

- 🚀 `UI` Add support for [Selfh.st](https://selfh.st/icons/) icons
- 🚀 `DOCKER` Add `watchatstart` option to disable automatic check during startup
