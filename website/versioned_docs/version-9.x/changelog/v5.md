# Version 5.x

Release history and details for the **WUD 5.x** series.

---

## [5.22.1](https://github.com/getwud/wud/releases/tag/5.22.1) · <small>November 27, 2022</small>

:::warning[**Breaking changes!**]
**Container-Centric Architecture**: WUD transitioned from an image-centric model to a **container-centric** model.
- The internal data model, REST API, and certain integrations were refactored.
- Please review the documentation before upgrading to evaluate any impacts on your setup.
:::

- 🚀 `DOCKER` / `DOCKER-COMPOSE` Add dry-run mode (pull new images only)
- 🚀 `DOCKER` Add ability to listen for Docker daemon events
- 🚀 `ECR` Add support for `public.ecr.aws` gallery
- 🚀 `MQTT` Add `update` device class for Home Assistant and send MQTT messages on container status changes
- 🚀 `MQTT` Add support for TLS and mTLS
- 🚀 `SMTP` Add ability to skip TLS certificate verification
- 🚀 `UI` Add Progressive Web App (PWA) support for mobile devices
- 🚀 `UI` Redesigned user interface
- 🚀 Add [Apprise](https://github.com/caronc/apprise) trigger
- 🚀 Add [CORS](../configuration/server/README.md) support
- 🚀 Add [Font Awesome](https://fontawesome.com/) and [Simple Icons](https://simpleicons.org/) support
- 🚀 Add [GitLab Registry](../configuration/registries/gitlab/README.md) support
- 🚀 Add [HTTPS/TLS support](../configuration/server/README.md)
- 🚀 Add ability to customize container display names and icons ([see `wud.display.name` and `wud.display.icon`](../configuration/watchers/labels.md#7-customize-display-name--icon))
- 🚀 Add ability to link container versions to release notes or changelogs ([see documentation](../configuration/watchers/labels.md#6-link-container-versions-to-changelogs--release-notes))
- 🚀 Add watcher-level option to watch all container digests
- 🚀 Add authentication system ([see documentation](../configuration/authentications/README.md))
- 🚀 Add Authentik configuration guide
- 🚀 Track container status (running, stopped, etc.)
- 🚀 Add custom timeout option for OIDC authentication providers
- 🚀 Add Docker Compose examples to documentation
- 🚀 Add [Docker Compose](../configuration/triggers/docker-compose/README.md) and [Docker](../configuration/triggers/docker/README.md) triggers
- 🚀 Add GitHub Container Registry, Hotio, and LinuxServer (`lscr.io`) registry support
- 🚀 Add OIDC automatic redirect capability and [OpenID Connect authentication](../configuration/authentications/oidc/README.md)
- 🚀 Add Quay registry support (`quay.io`) and support for [custom registries](../configuration/registries/custom/README.md)
- 🚀 Add support for `${prerelease}` variable in link templates
- 🚀 Add configurable trigger thresholds ([see documentation](../configuration/triggers/README.md))
- 🚀 Add tag transform rules before update analysis ([see documentation](../configuration/watchers/labels.md#4-transform-non-standard-tags-before-semver-analysis))
- 🚀 Add customizable title and body templates for triggers
- 🚀 Add option to trigger notifications individually or in batches
- 🚀 Add option to ignore or repeat previous update notifications
- 🚀 Allow excluding specific containers from being monitored
- 🚀 Allow storing [secrets in external files](../configuration/README.md#secret-management)
- 🚀 Automatically enable digest watching for non-semver tags
- 🚀 Digest management performance optimizations
- 🚀 Embed Material Design icons and Google Fonts in UI for offline access
- 🚀 Enable anonymous access by default for public registries (Docker Hub, GHCR, Quay)
- 🚀 Highlight containers with new digests in the UI
- 🚀 Improve test code coverage and log output
- 🚀 Publish WUD image to `ghcr.io` in addition to Docker Hub
- 🚀 Support `TZ` environment variable for local timezone configuration
- 🔧 Upgrade to Node.js 16 and watch individual containers instead of images
