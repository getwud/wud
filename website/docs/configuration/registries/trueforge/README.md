# TrueForge

![logo](trueforge.svg)

The `trueforge` registry module provides integration for the [TrueForge OCI Registry](https://trueforge.org/) and container images maintained by the [ContainerForge](https://trueforge.org/truetech/containerforge/) project.

:::info[Zero-Config for Public Images]
Public images hosted on TrueForge work out of the box with zero configuration. WUD automatically identifies TrueForge image URLs and tracks available tags.
:::
