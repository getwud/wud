# Version 8.x

Release history and details for the **WUD 8.x** series.

---

## [8.3.1](https://github.com/getwud/wud/releases/tag/8.3.1) · <small>July 31, 2026</small>

- 🚀 Add `WUD_REGISTRY_HUB_PUBLIC_SUPPRESSDIGESTWATCHWARNING` environment variable
- 🚀 `GITLAB` Add support for GitLab group access tokens
- 🐛 `DOCKER-COMPOSE` Fix trigger failing to detect containers in compose file
- 🐛 `PROMETHEUS` Reduce CPU usage
- 🐛 `OIDC` Fix issues when WUD starts while OIDC provider is temporarily unavailable
- 🐛 `DOCKER` Fix Docker container update when container is attached to multiple networks
- 🐛 `UI` Fix card overflow on home page
- 🔧 `TELEGRAM` Replace deprecated client with direct HTTP API calls

---

## [8.3.0](https://github.com/getwud/wud/releases/tag/8.3.0) · <small>July 14, 2026</small>

- 🚀 Add opt-in mode for trigger association
- 🚀 `TELEGRAM` Add SOCKS5/HTTP proxy support to Telegram trigger
- 🚀 Add runtime subpath proxy support with `WUD_SERVER_BASEPATH`
- 🚀 Add environment variable for default digest watching
- 🚀 `MQTT` Improve trigger performance and reliability
- 🚀 `DISCORD` Add avatar URL support
- 🐛 Fix digest comparison for single-platform manifests resolved from a manifest list
- 🐛 `NTFY` Fix basic authentication
- 🐛 `UI` Fix container filters on mobile devices
- 🐛 `ECR` Use link header for pagination
- 🐛 Fix Passport authentication handling
- 🐛 `DOCKER-COMPOSE` Fix handling of services defined without images
- 🐛 Fix text log format output
- 🔧 Update OIDC library dependencies
- 🔧 Add multi-stage UI build to Dockerfile
- 🔧 Add Playwright end-to-end tests

---

## [8.2.2](https://github.com/getwud/wud/releases/tag/8.2.2) · <small>February 26, 2026</small>

- 🚀 Add public Codeberg registry (`codeberg.org`) to default supported registries
- 🚀 Add public Forgejo registry (`code.forgejo.org`) to default supported registries
- 🐛 Fix startup errors encountered on specific system configurations

---

## [8.2.1](https://github.com/getwud/wud/releases/tag/8.2.1) · <small>February 25, 2026</small>

- 🐛 `APPRISE` Fix bad request error (*"Payload lacks minimum requirements"*)
- 🐛 `DISCORD` Fix bad request error (*"Invalid URL"*)
- 🐛 `NTFY` Fix token authentication
- 🐛 Fix metrics-related errors when Prometheus is disabled
- 🐛 Fix `wud.watch.digest` configuration not being respected
- 🔧 Migrate backend codebase to TypeScript

---

## [8.2.0](https://github.com/getwud/wud/releases/tag/8.2.0) · <small>February 14, 2026</small>

- 🚀 Add TrueForge Container Registry support (`oci.trueforge.org`)
- 🚀 Add Codeberg registry support
- 🚀 Allow disabling Prometheus metrics
- 🚀 Enable digest watching by default (except for Docker Hub images)
- 🚀 Ensure candidate tags retain the same number of semver parts
- 🚀 Ensure candidate tags retain the same prefix
- 🚀 Add support for `wud.compose.file` label
- 🚀 Add Rocket.Chat trigger
- 🚀 `SMTP` Allow `from` address to include a display name
- 🐛 Fix Docker Compose YAML parsing when multiple aliases are used
- 🐛 Ignore `.sig` signature tags during candidate version resolution
- 🔧 `UI` Migrate UI to Vue 3, Vuetify 3, and TypeScript
- 🔧 Upgrade runtime to Node.js 24 and switch to Alpine Linux base image

## [8.0.0](https://github.com/getwud/wud/releases/tag/8.0.0) · <small>January 10, 2025</small>

:::warning[**Breaking changes!**]
- **Registry Configuration**: Registry configuration structure has changed. Please update [your registry environment variables](../configuration/registries/README.md).
- **Storage State Reset**: Internal IDs have changed; your [existing state / storage](../configuration/storage/README.md) will be reset upon upgrading.
:::

- 🚀 `COMMAND` Add support for [Command](../configuration/triggers/command/README.md) trigger
- 🚀 `DOCKER` Add default healthcheck to the `wud` Docker image
- 🚀 `PUSHOVER` Add support for optional message TTL
- 🚀 `REGISTRY` Add support for configuring multiple registries of the same type
- 🚀 `TRIGGER` Add support for automatic or manual trigger execution modes
- 🚀 `TRIGGER` Improve `title`, `body`, and `link` template variables
- 🚀 `UI` Add ability to group containers by label
- 🚀 Brand new WUD logo! 🎉
- 🐛 `TRIGGER` Fix association issue between specific triggers and containers
- 🔧 Add Prettier code formatting and upgrade to Node.js 23
