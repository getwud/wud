Version 7.x

Release history and details for the WUD 7.x series.

7.2.0 · December 19, 2024​

  • 🚀 TRIGGER Add support for associating specific triggers with specific containers
  • 🚀 UI General UX improvements and styling polish
  • 🚀 UI / API Add support for manually running triggers to assist with testing

7.1.1 · November 12, 2024​

  • 🐛 NTFY Fix Basic and Bearer authentication headers

7.1.0 · November 11, 2024​

  • 🚀 GOTIFY Add support for Gotify trigger
  • 🚀 NTFY Add support for ntfy trigger
  • 🚀 PUSHOVER Add support for HTML templating
  • 🐛 UI Fix container list sorting behavior

7.0.0 · October 21, 2024​

Breaking changes!

WUD has moved to its own GitHub organization!

  • GitHub repository: https://github.com/getwud/wud
  • Docker image: https://hub.docker.com/r/getwud/wud
  • 🚀 UI Add support for Selfh.st icons
  • 🚀 DOCKER Add watchatstart option to disable automatic check during startup
